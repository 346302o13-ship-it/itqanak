# Roadmap

## Phase 1 — Foundation

Git, monorepo, Docker topology, configuration/secrets boundary, database migrations, health endpoints, storage abstraction, Worker heartbeat, backups, and recovery documentation.

## Phase 2 — Authentication

Email verification, password lifecycle, server-managed sessions, account security events, roles and permissions.

## Phase 3 — Catalog and student requests

Service catalog, student portal, request creation, consent, submission-key idempotency, and Core-controlled state transitions.

## Phase 4 — Administration and workflow

Admin dashboard, student/request management, assignment, deadlines, search, filters, audit trail, and authorization boundary.

## Phase 5 — Unified chat and secure files

Request conversations, text/image/audio/file/system messages, secure private storage, authorization checks, MIME sniffing, scanning, and signed delivery.

## Phase 6 — Quotes and finance

Quotes, invoices, credits, revisions, refunds, payment gateway integration, and append-oriented financial ledger.

## Phase 7 — Notifications

In-app and email delivery, outbox processor, WhatsApp Cloud API configuration, webhooks, consent, redaction, retries, and idempotency.

## Phase 8 — Content and production hardening

CMS, reports, analytics, Cloudflare rollout, performance/security hardening, off-server backup validation, and a full disaster-recovery exercise.
